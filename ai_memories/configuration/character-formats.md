# Character Sprite Formats — Multi-Format Support Design

## The Three Formats

### Format A — Classic Office Grid (current, 2 sizes)

A PNG arranged as **7 frames × 3 direction rows**. The existing loader reads this.

```
         F0    F1    F2    F3    F4    F5    F6
       walk1 walk2 walk3 jump1 jump2 slp1  slp2
      ┌─────┬─────┬─────┬─────┬─────┬─────┬─────┐
DOWN  │     │     │     │     │     │     │     │
      ├─────┼─────┼─────┼─────┼─────┼─────┼─────┤
UP    │(skip│skip │skip │skip │skip │skip │skip)│
      ├─────┼─────┼─────┼─────┼─────┼─────┼─────┤
RIGHT │     │     │     │     │     │     │     │
      └─────┴─────┴─────┴─────┴─────┴─────┴─────┘
```

LEFT is auto-generated by flipping RIGHT. UP row is stored but never rendered.

| Sub-variant | Frame size | Sheet total | Constant |
|---|---|---|---|
| A1 — Classic (original chars) | 16×32 px | 112×96 px | `CHAR_FRAME_W=16, CHAR_FRAME_H=32` |
| A2 — Scaled (char_cc.png) | 48×48 px | 336×144 px | `CHAR_FRAME_W=48, CHAR_FRAME_H=48` |

**Detection rule**: `width === CHAR_FRAMES_PER_ROW × frameW && height === 3 × frameH`

---

### Format B — Stream Avatar / Stream Avatars app style

A PNG arranged as **N animation-state rows × K frame columns**. Each row is one named animation. Direction is often baked in (facing right; LEFT flipped at runtime), or all 4 directions are stacked in groups of N rows.

**Stream Avatars app standard row order** (rows 0-indexed):
```
Row 0  — idle     (stationary breathing loop)
Row 1  — run      (fast movement)
Row 2  — sit      (seated / typing)
Row 3  — stand    (neutral standing)
Row 4  — jump     (bounce / action)
Row 5+ — custom   (sleep, wave, special, etc.)
```

**Typical frame counts per row**: 2–8 frames (variable per animation).

**Typical cell sizes**: 128×128 px, 256×256 px, 48×48 px.
- Each row can have a different number of frames.
- A companion **JSON manifest** is recommended to declare frame counts per row.

**Manifest format** (`char_cc_meta.json` alongside the PNG):
```json
{
  "format": "stream-avatar",
  "cellW": 48,
  "cellH": 48,
  "animations": [
    { "name": "idle",    "row": 0, "frames": 2, "fps": 4 },
    { "name": "run",     "row": 1, "frames": 4, "fps": 12 },
    { "name": "sit",     "row": 2, "frames": 2, "fps": 4 },
    { "name": "jump",    "row": 3, "frames": 4, "fps": 10 },
    { "name": "sleep",   "row": 4, "frames": 2, "fps": 3 },
    { "name": "special", "row": 5, "frames": 4, "fps": 8 }
  ],
  "directions": "right-only"
}
```

If no manifest exists, the loader falls back to detecting Format A by sheet dimensions.

**Direction handling options** for Format B:
- `"right-only"` — single direction per row; LEFT generated by flipping RIGHT; DOWN uses the same frames
- `"four-rows"` — every 4 rows form one animation group (down, up, right, left — or down, right, up, left)

---

### Format Detection Logic (dynamic loader design)

```
loadCharacterSprites(filePath, metaFilePath?)
  1. Read PNG → get png.width, png.height
  2. If metaFilePath exists and has "format":"stream-avatar" → use Format B loader
  3. Else try Format A detection:
       frameW = png.width  / CHAR_FRAMES_PER_ROW   (= 7)
       frameH = png.height / 3
       if (Number.isInteger(frameW) && Number.isInteger(frameH)) → Format A
  4. Else → log warning, return null (falls back to hardcoded templates)
```

**Output**: regardless of format, always produce the same `CharacterDirectionSprites`:
```typescript
{
  down:  SpriteData[][]   // [frameIndex][row][col]
  up:    SpriteData[][]   // (may alias to down or right for Format B)
  right: SpriteData[][]
}
```

## Animation → State Mapping (both formats)

### Format A frame slots → app states

| PNG frames | App state | Tool condition |
|---|---|---|
| F0 walk1, F1 walk2, F2 walk3 | `WALK` | any |
| F3 jump1, F4 jump2 | `TYPE` | write/edit/bash/task |
| F5 sleep1, F6 sleep2 | `TYPE` | read/grep/glob/webfetch |

### Format B animation rows → app states

| Animation row | App state | Trigger |
|---|---|---|
| `idle` | `IDLE` | agent inactive, wandering pause |
| `run` | `WALK` + `isActive` | agent walking toward seat while tool is running |
| `sit` | `TYPE` (any tool) | agent seated |
| `jump` / `special` | `TYPE` + write/bash/edit/task | computation tools |
| `sleep` | `TYPE` + read/grep/glob | lookup tools |
| `stand` | `WALK` + `!isActive` | normal wandering walk |

**Speed overrides** from manifest `fps` field take priority over `WALK_FRAME_DURATION_SEC` etc.

## What the Loader Needs to Emit

For Format B, after slicing rows into frames, remap to the existing `CharacterDirectionSprites` shape expected by `getCharacterSprites()`:

```typescript
// Mapping Format B animation names to CharacterDirectionSprites keys
const ANIM_TO_SLOT: Record<string, keyof CharacterDirectionSprites | null> = {
  idle:    null,      // stored separately as idleFrames[]
  run:     'walk',    // reuses walk slot at faster speed
  stand:   'walk',    // preferred walk source if present
  sit:     'typing',  // fallback for TYPE state
  jump:    'typing',  // primary for write/edit/task tools
  sleep:   'reading', // primary for read/grep tools
  special: null,      // stored separately as specialFrames[]
}
```

`idle` and `special` go into new optional fields on `CharacterDirectionSprites` (non-breaking addition):

```typescript
interface CharacterDirectionSprites {
  down:  SpriteData[][]
  up:    SpriteData[][]
  right: SpriteData[][]
}

// Extended (new fields, optional — Format B only)
interface ExtendedCharacterDirectionSprites extends CharacterDirectionSprites {
  idleAnim?: SpriteData[][]     // idle row from stream-avatar sheet
  runAnim?:  SpriteData[][]     // run row (if distinct from walk)
  specialAnim?: SpriteData[][]  // special row
}
```

## Adding a New Stream-Avatar Sheet (workflow)

1. Drop `char_NAME.png` into `webview-ui/public/assets/characters/`
2. Create `char_NAME_meta.json` in same folder with the manifest above
3. In `src/assetLoader.ts`, add `char_NAME` to the loader list (or make it auto-discover all `char_*.png` with companion `_meta.json`)
4. The loader emits `ExtendedCharacterDirectionSprites`, pushed to all 6 palette slots (or as many as you want)
5. Rebuild → F5 to test
